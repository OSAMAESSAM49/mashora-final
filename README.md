# مشورتي 🌿

تطبيق لإدخال حالات المشورة اليومية (ما قبل الزواج، تنظيم الأسرة، الحامل، الأطفال) وتصديرها على شيت الإكسيل الرسمي بنفس التنسيق.

- بيشتغل من غير نت بعد أول فتحة، ويتثبت على الموبايل زي أي تطبيق.
- بيانات الحالات بتتخزن على الجهاز بس، ومش بتترفع على أي مكان.

## التشغيل على GitHub Pages
1. ارفع كل الملفات دي في جذر الـ repository.
2. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** / **(root)** ← Save.
3. بعد دقيقة الرابط هيبقى: `https://USERNAME.github.io/REPO-NAME/`

## التثبيت على الموبايل
- **أندرويد (Chrome):** افتح الرابط ← زرار "تثبيت" في الصفحة الرئيسية.
- **آيفون (Safari):** افتح الرابط ← زرار المشاركة ⬆️ ← "إضافة إلى الشاشة الرئيسية".
